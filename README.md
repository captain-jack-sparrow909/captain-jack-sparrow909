### How I build

- **Grounded before generative** — outputs should trace back to real evidence.
- **Human control by design** — consequential actions deserve review, approvals, and clear boundaries.
- **Products, not demos** — auth, permissions, failure states, observability, accessibility, and deployment are part of the work.
- **Fast, but legible** — strong abstractions, documented decisions, and systems another engineer can operate.
